description: The Monday review, written from three commands. What needs a decision, the week, the compliance state, then the five things that matter this week.
---

Run these three, in this order, and write the review from what they return. Do not write anything they do not support.

```
npm run seafood -- attention
npm run seafood -- week
npm run seafood -- compliance
```

Then write it in this shape, no more than a page:

1. **The week in one line.** Kilograms landed, kilograms packed and the yield, cases in store, open orders, money owed to fishers.
2. **The one that cannot wait.** Any held landing, any lot over the histamine limit, any shellfish without clearance, any export blocked on an E-cert or a histamine result, by name. Empty is the system working.
3. **The line.** Yield by species against standard; any run flagged LOW with its note.
4. **The store.** Cold store state, product near or past use-by, what should be sold or frozen this week.
5. **The money.** Dispatches at catch weight this week; what is owed to which fisher and when they are due a settlement.
6. **Permits and paperwork.** Fisher permits expiring, products missing an allergen or origin statement.
7. **The five things to do this week.** Picked from the attention list, weighted food safety first, legal second, condition third, money fourth. Say why each made the list.
8. **One thing to decide.** The single item that needs a person, not a process.

Add `npm run view` if the operator wants pages for a meeting: same numbers, the business's brand, and they print.
