---
description: Yields by run and by species against your own standard, the numbers that decide whether the fillet line made money this week.
---

1. Run `npm run seafood -- runs` (add `--days=7` for the week, `--days=90` for the season).
2. Present the by-species table first: kilograms in, kilograms out, yield, standard.
3. Then name every run flagged LOW, with the lot, the vessel and any note on the run. Convert the gap into kilograms of product: at a 42% standard, one point on 820 kg of snapper is 8.2 kg of fillet.
4. If a vessel's fish yields low run after run, say so with the runs listed. It may be the fish (handling on board, size) and it is a conversation with the fisher, not a guess.
