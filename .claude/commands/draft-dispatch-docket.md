---
description: Draft the dispatch docket and packing list for an order, every case with its net weight, lot, vessel, catch area and histamine result. Drafts only.
---

1. Run `npm run docs -- dispatch-docket`. One file per order with cases lands in `docs-out/dispatch-docket/`.
2. For an export order, check the E-cert reference is on it. If it reads NOT YET ON RECORD, the order is not ready to leave; say so.
3. The packing list is also the recall answer printed in advance. Keep a copy with the order. **Nothing sends from here.**
