---
description: Draft the settlement statement for a fisher, every lot at its price less the deduction, in the business's brand. Drafts only, never sends.
---

1. Run `npm run docs -- fisher-settlement-statement`. One file per settlement lands in `docs-out/fisher-settlement-statement/`.
2. A draft settlement is not yet paid; say so in any covering note. A paid one is final.
3. If the operator wants a covering email, write it to `drafts/` in plain words: the period, the lots, the net, when it will be paid. **Nothing sends from here.**
